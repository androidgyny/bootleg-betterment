Bootleg Betterment
=================
English adaptations and repairs for unusual Famicom / NES games by P3.

GitHub Pages: https://androidgyny.github.io/bootleg-betterment/
Repository: https://github.com/androidgyny/bootleg-betterment

Games
-----
Final Fantasy IV — Trilogy English Beta 1
Heroes of Might and Magic — HoMM English 1.6.1
Saint Seiya — English 1.0.1

Open index.html for descriptions, credits, screenshots, source ROM SHA-256
requirements, patch downloads and assembly instructions. No ROMs are included.

FFIV includes Windows/macOS/Linux launchers for a Python 3 assembly script.
It requires all three original Chinese ROMs and verifies the exact Beta 1 output.
FCEUmm is the tested compatible RetroArch core. The combined English manual
uses verified Beta 1 screenshots (manual revision 2, November 1, 2026).

Validation
----------
The FFIV patch kit reproduced Beta 1 byte-for-byte. Wrong source order and
output overwrite attempts were rejected. Python was tested on Windows;
the macOS/Linux launcher has not been run on those operating systems.
See verification.json and manuals/FFIV-Beta-1-manual-check.json for details.

Maintenance
-----------
Keep download dates tied to actual package revisions. Compare the version
and output SHA-256 when deciding whether a ROM needs an upgrade. Changes
to the page or manual do not necessarily change the patched game.

This is a static website. GitHub Pages serves the root of the main branch.
